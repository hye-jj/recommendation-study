## recommendation-study
추천 알고리즘/추천시스템 학습

#### 고객 구매데이터 기반 추천시스템

- 고객 구매데이터를 분석하여 고객별 구매 특성과 구매 패턴 탐색
- 군집분석을 활용하여 고객을 유형별로 분류하고 추천 대상 고객의 특성 분석
- 추천 알고리즘을 적용하여 고객 맞춤형 상품 추천 시스템 구현

① 프로젝트 목표 <br>
고객 구매 데이터를 분석하여 고객별 특성을 파악하고,  <br>
고객 세분화 및 추천 알고리즘을 적용하여 개인화 추천 가능성을 탐색 <br>
 <br>
② 담당 역할 <br>
팀 프로젝트에서 데이터 전처리 및 분석 수행 <br>
군집분석을 활용한 고객 유형 분류 <br>
추천시스템 및 추천 알고리즘 적용 과정 구현 및 결과 분석 <br>
flask를 사용한 간단한 서비스 화면 구현 <br>
 <br>
③ 사용 기술 <br>
Python · Pandas · Scikit-learn · Clustering · Recommendation Algorithm <br>
 <br>
④ 주요 수행내용 <br>
고객 구매 데이터 전처리 및 탐색적 데이터 분석 <br>
군집분석을 활용한 고객 유형별 특성 분석 <br>
추천시스템 및 추천 알고리즘을 적용하여 추천 결과 생성 <br>
분석 및 추천 결과를 발표자료로 정리 <br>
 <br>
⑤ 결과 / 배운점 <br>
고객 데이터를 단순 분석하는 데 그치지 않고 고객 세분화 → 추천 알고리즘 적용 → 추천 결과 분석의 과정을 경험하며  <br>
추천시스템의 기본적인 구조와 데이터 기반 개인화 방법을 학습 <br>
